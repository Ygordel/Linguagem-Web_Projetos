## 📚 Sobre o curso

Este repositório apresenta um curso prático de **Desenvolvimento Web**, com foco na construção de páginas e projetos utilizando as principais tecnologias da área.

Durante as aulas serão abordados conceitos de **HTML, CSS, JavaScript e Bootstrap**, combinando teoria, exercícios e desenvolvimento de projetos práticos.

O objetivo é proporcionar uma base sólida para criação de páginas web modernas, organizadas, responsivas e interativas.

---

## 🎯 Objetivos

Ao longo do curso, você irá aprender a:

- Estruturar páginas utilizando HTML5;
- Trabalhar com elementos, atributos e formulários HTML;
- Criar estilos utilizando CSS3;
- Organizar layouts e componentes;
- Trabalhar com cores, fontes, margens e espaçamentos;
- Criar páginas responsivas;
- Utilizar JavaScript em páginas web;
- Manipular elementos HTML através do DOM;
- Criar interações com o usuário;
- Utilizar eventos JavaScript;
- Utilizar o framework Bootstrap;
- Criar layouts responsivos;
- Desenvolver projetos práticos;
- Organizar arquivos de projetos web;
- Publicar projetos utilizando Git e GitHub.
